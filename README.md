# 奶龙中心.com

奶龙、奶蛙主题网址导航的本地静态网站首版。

## 本地运行

在此目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 功能

- 30 个当前可访问的奶龙/奶蛙主题站点
- 搜索、分类筛选与本地收藏
- “奶龙正在护送”跳转动画
- 随机站点入口
- 三个小游戏预留区域
- 桌面与手机响应式布局

## 素材说明

跳转动画使用[奶龙官网](https://www.nailoong.com/)公开展示的静态角色图片，角色的弹跳、移动和场景效果由 CSS 实现。本站与所列学校及角色版权方无官方关联。
